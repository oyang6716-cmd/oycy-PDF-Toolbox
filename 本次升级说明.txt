oycy的PDF工具箱 · PDF 页面预览与局部排版升级版

这是源码项目，需要 GitHub Actions 自动构建 Windows EXE。

重点功能：
1. A4、A3、Letter 横纵向/原始尺寸/自定义毫米纸张大小
2. 每页独立旋转、缩放、左右与上下对齐
3. 多页批量设置、自动排版、编辑器内移动/移除页面
4. 实时 PDF 预览及处理完成后的输出预览
5. 合并 PDF 时应用逐页编辑设置，尽量保留矢量画质

注意：局部编辑应用到“合并PDF”导出；其他工具输出时保留原有功能并不自动接入逐页排版。
上传到 GitHub 时，除了 app.py，还必须一起上传 page_layout.py 和 page_editor_ui.py。
详见 README.md。
